Configurações da rádio

Cloudflare R2 (armazenamento de áudio)

Configure o R2 para hospedar MP3s fora do GitHub. Arquivos grandes (mais de 50 MB) precisam do R2. As credenciais ficam salvas só neste navegador.

Lembre de configurar o CORS no R2 para permitir uploads do seu domínio do GitHub Pages.

Publicar no GitHub

Envia músicas, vinhetas, programas e grade direto para o repositório. O GitHub Pages atualiza a rádio em 1 a 2 minutos.

O token fica salvo só neste navegador. Sem ele, ninguém consegue publicar, mesmo que abra esta página.
